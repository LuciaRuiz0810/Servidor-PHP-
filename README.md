> Repositorio de ejercicios y prácticas de PHP realizados durante el ciclo de Desarrollo de Aplicaciones Web

## 📖 Sobre este repositorio

Este repositorio contiene todos los ejercicios, prácticas y proyectos desarrollados en PHP durante el módulo de **Desarrollo Web en Entornos Servidor** del ciclo formativo de DAW.

## 📁 Contenido

El repositorio incluye ejercicios sobre:

- **Sintaxis básica de PHP**: Variables, operadores, estructuras de control
- **Funciones**: Creación y uso de funciones
- **Arrays**: Manipulación de arrays y estructuras de datos
- **Formularios**: Procesamiento y validación de datos
- **Sesiones y Cookies**: Gestión de estado de usuario
- **Bases de datos**: Conexión y operaciones con MySQL
- **Programación Orientada a Objetos**: Clases, herencia, interfaces
- **Proyectos prácticos**: Aplicaciones web completas

## 🚀 Cómo usar este repositorio

### Requisitos previos

- PHP >= 7.4
- Servidor web (Apache/Nginx) o usar el servidor integrado de PHP
- MySQL (opcional, según el ejercicio)
